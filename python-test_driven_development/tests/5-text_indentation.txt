========================
How to use 5-text_indentation.py
========================

Using ``text_indentation``
---------------------

Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Checking standard text:
    >>> text_indentation("Holberton. School? Python: It's great.")
    Holberton.
    <BLANKLINE>
    School?
    <BLANKLINE>
    Python:
    <BLANKLINE>
    It's great.
    <BLANKLINE>

Checking text with leading/trailing spaces:
    >>> text_indentation("   Hello world. How are you?   ")
    Hello world.
    <BLANKLINE>
    How are you?
    <BLANKLINE>

Checking TypeError when text is not a string:
    >>> text_indentation(123)
    Traceback (most recent call last):
    TypeError: text must be a string
